# Assistant × Codex Worklog

Эта папка — не часть книги и не часть материалов Плотникова.

Назначение: сохранить рабочую память нашего взаимодействия по созданию мультиагентной системы и управлению задачами Codex, чтобы новый чат можно было начинать не с нуля.

Здесь фиксируются:

- где мы остановились;
- какие PR уже прошли;
- какие решения приняты;
- какие задачи отложены;
- как правильно продолжать работу с Codex;
- какие правила общения и проверки оказались важными.

Здесь не хранятся:

- сырой текст книг;
- материалы Плотникова;
- главы будущей книги;
- приватные Google Drive ссылки;
- полный дословный лог чата.

Эта папка — операционная память процесса `ChatGPT ↔ Сергей ↔ Codex`, а не содержательный корпус книги.

## С чего начинать новый чат

Открой файл:

- [restart-prompt.md](./restart-prompt.md)

Затем проверь:

- [current-state.md](./current-state.md)
- [roadmap.md](./roadmap.md)
- [working-protocol.md](./working-protocol.md)
