# Sync packages

This directory stores connection packages between a source chapter and our future chapter.

A sync package records what we take as a function, which project sources are connected, and which Svod safeguards are active. It should guide transformation into an independent chapter draft without copying, close retelling, or preserving raw source text.

## Standard chapter artifact chain

For each new manually uploaded chapter, use this fixed processing chain:

1. plotnikov map
2. sync package
3. chapter draft
4. reviewed chapter
5. approved chapter
6. update package

Review queue entries must include clickable GitHub links.
