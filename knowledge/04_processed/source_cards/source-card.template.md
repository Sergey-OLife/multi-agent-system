# Source Card Template

## Metadata

- `source_id`: stable unique source identifier.
- `title`: source title.
- `author`: source author or responsible organization.
- `version_or_edition`: version, edition, publication date, or revision marker.
- `language`: primary source language.
- `source_type`: book, article, interview, course, note, dataset, or other source category.
- `copyright_status`: public domain, licensed, owned, permission granted, private reference, unknown, or other status.
- `storage_location`: approved storage path or external location reference; do not include raw copyrighted content.
- `priority_level`: project / curated / processed / general.
- `project_use`: how this source may support the project.
- `what_to_preserve`: concepts, structure, formulas, terminology, or facts that should be preserved during synthesis.
- `what_not_to_copy`: protected expression, long passages, proprietary layouts, private data, or anything that must not be reused verbatim.
- `synthesis_role`: role in the final synthesis, such as foundation, contrast, example bank, method input, or validation source.
- `related_agents`: agents that may use this card.
- `processed_status`: not_started / in_progress / processed / needs_review / deprecated.
- `last_updated`: ISO date of the last card update.
