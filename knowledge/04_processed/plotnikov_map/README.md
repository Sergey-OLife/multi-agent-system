# Plotnikov chapter maps

This directory stores maps of source chapters without long quotes.

A Plotnikov map records the function of the material: what role the source chapter can play in the project, which ideas need transformation, and what synchronization decisions are needed. It does not retell the source text and must not become a substitute for the raw book.

These maps are inputs for `synchronization_mapper`, which connects the manually uploaded chapter material to independent drafts, sync packages, and project guardrails.

## Standard chapter artifact chain

For each new manually uploaded chapter, use this fixed processing chain:

1. plotnikov map
2. sync package
3. chapter draft
4. reviewed chapter
5. approved chapter
6. update package
