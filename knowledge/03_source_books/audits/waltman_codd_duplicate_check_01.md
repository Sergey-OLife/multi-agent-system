# Duplicate Check 01 — Waltman / Codd Socratic Source

Дата: 2026-05-17
Статус: proposal / requires file-level verification

## 1. Что проверяется

Проверяется возможный дубль источника, связанного с `waltman_codd_macfarr_moore_socratic_questioning`.

В проекте обнаружены два имени файла, которые могут относиться к одному и тому же источнику:

1. `Сократовский_диалог_Скотт_Уолтман,_Р_Трент_Кодд.pdf`
2. `uoltman_skott_kodd_iii_trent_makfarr_linn_mur_bret_sokratovs.pdf`

## 2. Риск

Если создать две карточки, система получит ложное ощущение двух независимых источников. Это исказит вес сократического блока и может раздуть агентную логику.

## 3. Текущее решение

Пока сохраняется один canonical source_id:

`waltman_codd_macfarr_moore_socratic_questioning`

Второй source_id не создавать.

## 4. Что нужно проверить вручную

Перед финальным статусом нужно открыть оба файла и сверить:

- титульную страницу;
- авторов;
- год/издание;
- оглавление;
- количество страниц;
- структуру глав;
- перевод или OCR-версию;
- наличие предисловий/приложений.

## 5. Возможные исходы

### A. Полный дубль

Действие:

- оставить один canonical filename;
- второй файл пометить как `archive_duplicate`;
- не менять source_id.

### B. Альтернативная версия одного источника

Действие:

- оставить один canonical source_id;
- добавить `alternate_file` в source-location entry;
- указать, какая версия предпочтительнее для targeted reading.

### C. Разные источники

Действие:

- только тогда рассмотреть второй source_id;
- создать отдельную source card;
- обновить registry отдельным PR.

## 6. Временное правило использования

До проверки дубля:

- не создавать новых source cards по этому блоку;
- не считать два файла двумя независимыми источниками;
- использовать только существующую карточку как рабочий указатель;
- не заявлять, что весь источник полностью проверен.

## 7. Next action

Открыть оба файла, сверить титульные страницы и оглавления. После проверки обновить этот record или создать `duplicate_check_result_01`.
